# Documentation resources

- `diagrams/`: original project diagrams; SVG files are editable and can be rendered directly by GitHub.
- `waveforms/`: add selected waveform screenshots from simulation.
- `vivado/`: add block-design, address-map, timing, and utilization screenshots.
- `board/`: add board setup and end-to-end output evidence.
- `papers/references.md`: learning links and attribution notes.

Replace conceptual diagrams after the corresponding architecture is reviewed. Do not present a placeholder as proof of implemented hardware.
